03 / 11

Servis kayıtları

Temel servisleri her senaryoda ekleyin. PKCS#11 katmanını ancak sağlayıcı adaptörünü kaydettikten sonra etkinleştirin.

Program.cs
using ImzaKit.DependencyInjection;
using ImzaKit.Pkcs11.Abstractions;
using Microsoft.Extensions.DependencyInjection;

var services = new ServiceCollection();
services.AddImzaKitCore();

// Kart/HSM ile imzalama kullanılıyorsa:
services.AddSingleton<IPkcs11Provider, MyPkcs11Provider>();
services.AddImzaKitPkcs11();

using ServiceProvider provider = services.BuildServiceProvider();

AddImzaKitCore, özet/CMS/PAdES servisleri ile API güvenlik ve işlem servislerini kaydeder. AddImzaKitPkcs11, kayıtlı sağlayıcı üzerinden süreç içi orkestratörü hazırlar.

04 / 11

İmzalı PDF doğrulama

Doğrulama raporunu tek bir “geçti/kaldı” bayrağına indirgemeyin. PDF aralığı, kriptografik sonuç ve güven kararı ayrı alanlardır.

C#
using ImzaKit.Verify.Validation;

byte[] signedPdf = File.ReadAllBytes("signed-document.pdf");
PadesValidationReport report = PadesValidator.Validate(signedPdf);

Console.WriteLine($"Durum: {report.Status}");
Console.WriteLine($"ByteRange: {report.ByteRangeStatus}");
Console.WriteLine($"Kriptografi: {report.CryptographicStatus}");
Console.WriteLine($"Güven: {report.TrustStatus}");

foreach (ValidationFinding finding in report.Findings)
    Console.WriteLine($"{finding.Code}: {finding.Message}");

Çevrimdışı güven doğrulaması

C# / Alpha.4
var trust = new TrustStoreSnapshot("trust-2026.08",
    [new TrustAnchor(rootCertificate,
        [ValidationProfile.GeneralX509, ValidationProfile.TurkiyeNes])]);
var policies = new CertificatePolicyCatalog("policy-2026.08", policyEntries);
var context = new ValidationContext(
    ValidationProfile.TurkiyeNes,
    DateTimeOffset.UtcNow,
    ValidationTimeSource.CurrentSystemTime,
    trust,
    policies,
    embeddedIntermediates,
    localIntermediates,
    revocationEvidence);

PadesValidationReport report = PadesValidator.Validate(signedPdf, context);
if (report.Findings.Any(x => x.ReasonCode == ValidationReasonCode.RevocationDataUnavailable))
    Console.WriteLine("Uygun çevrimdışı OCSP/CRL kanıtı yok.");

Sınırlamalar

Sistem güven deposu, AIA, OCSP ve CRL ağ adresleri otomatik kullanılmaz. Sürümlü güven/politika girdileri ile kanıtların güvenli dağıtımı çağırana aittir.

Offline trust validation

Use ValidationContext with GeneralX509 or TurkiyeNes. A RevocationDataUnavailable finding requires additional caller-supplied evidence.

Limitations

No system trust store or network endpoint is consulted. The caller owns authenticated distribution of snapshots, policies, intermediates, and revocation evidence.

05 / 11

Hazırla → imzala → tamamla

Özel anahtar başka bir süreçte, istemcide veya HSM sınırında kalacaksa iki aşamalı akışı kullanın.

01Kimliği oluşturoperationId + belge özeti
02PreparePDF placeholder + signed attributes
03Haricî imzaDigestInfo kart/HSM’de imzalanır
04CompleteCMS oluşturulur ve PDF’ye gömülür
05ValidateSon belge yeniden doğrulanır
Temel sözleşme
using ImzaKit.Core.Signing;
using ImzaKit.PAdES.Completion;
using ImzaKit.PAdES.Preparation;

PadesSignaturePreparer preparer = provider.GetRequiredService<PadesSignaturePreparer>();
PadesSignaturePreparation preparation = preparer.Prepare(
    operationId,
    documentSha256,
    originalPdf,
    cmsCapacity: 16_384,
    signingCertificateDer,
    certificateFingerprintSha256,
    prepareVersion: 1);

// preparation.SignaturePreparation içindeki imzalanacak veri
// güvenli sınırda imzalanır ve signatureValue döner.
SignatureCompletion completion = SignatureCompletion.Create(
    operationId, 1, certificateFingerprintSha256, signatureValue);

byte[] signedPdf = PadesSignatureCompleter.Complete(
    preparation, completion, signingCertificateDer);

Önemli: operationId, prepareVersion ve sertifika parmak izi tamamlama sırasında hazırlama kaydıyla aynı olmalıdır. cmsCapacity, nihai CMS boyutunu karşılamalıdır.

06 / 11

IPkcs11Provider adaptörü

ImzaKit üreticiye özel native kitaplık paketlemez. Bu arayüz, kütüphane ile kart/HSM sürücüsü arasındaki dar ve test edilebilir sınırdır.

Yaşam döngüsü
Initialize() → işlem → FinalizeProvider(). Başlatma/tamamlama çağrılarını sağlayıcının thread-safety kurallarına göre eşleyin.
Token ve oturum
DiscoverTokens(), OpenSession(slotId), Login(session, pin), Logout(session), CloseSession(session).
Sertifika ve anahtar
FindCertificates(session) ile sertifikaları döndürün; seçilen sertifikanın CKA_ID değeriyle FindPrivateKey çağrısını eşleyin.
İmza işlemi
SignRsaPkcs1Sha256(session, keyHandle, digestInfo), RSA PKCS#1 v1.5 SHA-256 imza değerini döndürür. Girdi ham belge değil, hazırlanmış DigestInfo’dur.
Gizli veri sınırı. PIN’i kalıcı belleğe çevirmeyin, loglamayın veya telemetry’ye göndermeyin. Özel anahtar kart/HSM’den çıkmamalıdır.

Doğrulanmış Windows profilleri

İlk profil AKİS (akisp11.dll, NativePkcs11ProviderOptions.ForAkis()). İkinci profil eToken (eTPKCS11.dll, ForEtoken()). Üç parametreli Pkcs11NativeLibraryLoader.Load seçilen profilin dosya adlarını alır. eToken varsayılan allowlist kökleri %ProgramFiles%\SafeNet\Authentication\SAC\x64 ve %ProgramFiles%\Thales\SafeNet Authentication Client yollarıdır; System32 varsayılan değildir. Vendor DLL paketlenmez. Fiziksel eToken kabulü ayrı laboratuvar listesidir; MVP çıkış kapısı AKİS kartına bağlı kalır.

07 / 11

Süreç içi orkestrasyon

Web/API istemcisine bölünmüş bir prepare/complete protokolü gerekmiyorsa, kayıtlı sağlayıcıyla tam akışı tek çağrıda yürütün.

DI üzerinden
using ImzaKit.DependencyInjection;
using ImzaKit.Pkcs11.Models;

var orchestrator = provider.GetRequiredService<InProcessPadesSigningOrchestrator>();

InProcessSigningResult result = orchestrator.Execute(
    originalPdf,
    slotId,
    certificate,
    pin.AsSpan());

byte[] signedPdf = result.SignedPdf;
Console.WriteLine($"İşlem: {result.Operation.State}");
Console.WriteLine($"Doğrulama: {result.Validation.Status}");

Bu akış token keşfi ve sertifika seçimini uygulamanın sorumluluğunda bırakır. Kullanıcı onayı/PIN arayüzü de uygulama veya üretici katmanında yönetilir.

10 / 11

Sorun giderme

En sık görülen belirtileri doğru katmana bağlayın; kart, CMS, PDF ve güven politikası birbirinden bağımsız hata alanlarıdır.

TrustStatus neden Indeterminate?
Kriptografik doğrulama güven zinciri kararı değildir. Kurumsal root store, ara sertifikalar ve OCSP/CRL politikasını uygulama katmanında çalıştırın.
CMS placeholder neden yetersiz?
Sertifika zinciri ve signed attributes nihai CMS boyutunu büyütür. cmsCapacity değerini hedef sertifikalarla ölçüp güvenli pay bırakın.
Token/sertifika bulunamıyor
Native kitaplık mimarisini, slot görünürlüğünü, oturum türünü ve CKA_ID eşlemesini kontrol edin. Seri numarası/PIN gibi değerleri loglamayın.
PDF ön kontrolde reddediliyor
PdfPreflightException.Code değerini yakalayın. Dosyayı sessizce dönüştürmek yerine desteklenen PDF üretim hattını düzeltin.
Tamamlama eşleşmiyor
operationId, prepareVersion, sertifika parmak izi ve imzalanan DigestInfo’nun aynı hazırlama işlemine ait olduğunu doğrulayın.
