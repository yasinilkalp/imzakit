# Güvenlik Politikası

## Desteklenen sürüm

ImzaKit halen ön sürümdür. Güvenlik düzeltmeleri aktif NuGet ön sürümü `1.0.0-alpha.7` ve gerektiğinde onu izleyen en güncel ön sürüm için değerlendirilir. Önceki alpha paketleri desteklenmez.

## Güvenlik açığı bildirme

Henüz düzeltilmemiş bir güvenlik açığı için public issue açmayın. GitHub deposundaki **Security → Advisories → New draft security advisory** yolunu kullanarak private Security advisory oluşturun:

https://github.com/yasinilkalp/imzakit/security/advisories/new

Bildirimde mümkünse şunları sağlayın:

- Etkilenen sürüm, modül ve çalışma ortamı
- Yeniden üretim adımları veya en küçük kanıt kodu
- Beklenen güvenlik etkisi ve saldırı önkoşulları
- Bilinen geçici önlem
- Koordineli açıklama için önerilen zamanlama

PIN, özel anahtar, gerçek kimlik sertifikası veya üretim secret'ı göndermeyin. Kanıt için yapay ve geri alınabilir test verileri kullanın.

Bakım ekibi bildirimi en iyi çabayla yedi gün içinde aldığını teyit etmeyi hedefler. İnceleme, düzeltme veya yayın tarihi için önceden süre garantisi verilmez. Doğrulama sonrasında kapsam, koordineli açıklama ve kredi bilgisi bildirimi yapan kişiyle özel kanalda değerlendirilir.

Genel kullanım soruları ve güvenlik açığı içermeyen sertleştirme önerileri normal issue şablonlarıyla paylaşılabilir.
